# Staple Price Book

A small, vibecoded app for watching how the groceries I actually buy get more expensive.

Existing grocery and budget apps do too much: receipts, shopping lists, spending totals, deals. This one only records staple prices (milk, eggs, potatoes, chicken) and shows how those unit prices move over time.

It is a personal experiment in building with LLMs, not a product. The glossary, spec, and research notes in this repo are the brief those models work from.
